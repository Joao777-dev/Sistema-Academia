1.0 Requisitos funcionais

RF01 – Cadastrar aluno

O sistema deverá permitir que usuários autorizados cadastrem alunos.

RF02 – Consultar aluno

O sistema deverá permitir a consulta das informações cadastradas.

RF03 – Cadastrar profissional

O sistema deverá permitir o cadastro dos profissionais responsáveis pelo acompanhamento dos alunos.

RF04 – Cadastrar plano

O sistema deverá permitir o cadastro dos planos oferecidos pela academia.

RF05 – Cadastrar matrícula

O sistema deverá permitir associar um aluno a um plano.

RF06 – Consultar situação da matrícula

O sistema deverá apresentar a situação da matrícula, indicando se ela está ativa, próxima do vencimento ou vencida.

RF07 – Cadastrar exercício

O sistema deverá permitir o cadastro dos exercícios disponíveis para utilização nas fichas.

RF08 – Consultar histórico

O sistema deverá permitir o armazenamento e consulta de informações históricas relevantes, respeitando as permissões de cada usuário.

2.0 Requisitos Não Funcionais

RNF01 – Segurança 
O sistema deverá proteger os dados armazenados e restringir o acesso às 
funcionalidades conforme o perfil do usuário. 

RNF02 – Autenticação 
O acesso às áreas restritas deverá exigir autenticação. 

RNF03 – Usabilidade 
A interface deverá apresentar navegação simples e informações organizadas de maneira 
compreensível. 

RNF04 – Acessibilidade 
A interface deverá ser desenvolvida considerando princípios das WCAG 2.2, buscando 
atender usuários com diferentes necessidades de acessibilidade.

RNF05 – Desempenho 
As operações de consulta e registro deverão apresentar tempo de resposta adequado 
ao volume esperado de dados da organização. 

RNF06 – Disponibilidade 
O sistema deverá estar disponível durante o horário de funcionamento da organização, 
considerando a infraestrutura adotada. 

RNF07 – Integridade 
O banco de dados deverá utilizar mecanismos que reduzam inconsistências e 
duplicidade indevida de informações. 

RNF08 – Escalabilidade 
A arquitetura deverá permitir a expansão futura do número de usuários, alunos e 
funcionalidades. 

RNF09 – Manutenibilidade 
O sistema deverá ser organizado de forma modular, facilitando correções e evolução.
